# OilCast v6 / v7：穩定超越價格不變基準的驗證

**結論：目標仍未達成，四油品升級門檻未通過。** 這輪已實作並驗證新的訓練方式、資料來源和逐週回測，但不能據此宣稱模型已穩定勝過基準。

## 驗收方式

- 保持週一台北時間 00:00 預測下週一的七天範圍，每週只使用當時已知資料及已結算標籤重新訓練。
- 各版本保留完整 1,412 週歷史輸入；舊資料的基礎時間權重不低於新資料的一半。汽油共用調幅，但 92、95、98 與柴油各自計分、各自過門檻。
- 五個原定舊年度 13 週視窗，加上兩段近期 39 週。2025 年夏季與近期視窗重疊，不當成獨立證據；四個獨立舊年度至少三個改善，且不得有超過 0.005 元／公升的退步。
- 保留原有近期改善要求：v6 兩段各超過 0.015；v7 最近期一段超過 0.01。另要求兩段近期均改善超過 0.01，並檢查方向與錯誤變動率。
- 最後 13 週每種油品仍須改善超過 0.01 元／公升。模型選擇先寫入檔案並雜湊，才計算最後區間。此區間過去已看過，屬歷史診斷，不能當成新的盲測或未來績效證明。

## 實際新增內容

五類固定模型，各比較市場／政策資料與加入外部風險資料的版本，共 10 個候選：平滑絕對誤差線性模型、絕對誤差提升樹、全歷史模型加政策殘差模型、全歷史模型加政策專家，以及上漲／不變／下跌機率混合模型。

機率混合模型保留價格不變的機率質量，不做類別平衡或調價週過度抽樣；由條件分布的中位數決定調幅。平行計算只加快獨立週次，已驗證與循序計算一致。原有 v6 MAE 訓練及 v7 神經網路絕對損失修正保留在同一草稿變更中；這些 Python 研究模型尚未整合為 Android 簽署推論包。

## 固定資料與缺口

- GDELT v1：2013-04-05 至 2026-10-30 的 709 個週五檔案，706 個成功解析。保留來源網址、雜湊與大小；僅保留統計數值，不保留文章內文。
- 新聞事件依 DATEADDED 首次收錄時間與保守發布延遲決定可用時間，不依事件發生日倒填。星期五取樣並非整週新聞；能源訊號是網址字詞代理，並非完整文章理解。
- 中油：補回 2026-03-28 至 2026-10-31 的 32 份鄰國零售價表，32 份的四種台灣參考價均與固定官方週價格核對通過。最後一份晚於資料集中最後預測起點，因此實際有 31 個起點可用。
- **2019–2025 鄰國價格仍未補齊；零售價比較也不是官方稅前限價。** 本次讀取歷史網頁不能證明當年 HTML 版本，來源明列未驗證原始版本，不將缺值填成已知零價。
- MOEA 日報價延用三個日曆日的可用時間假設；現下載的歷史報價不等於原始發布版本。原本 2019–2025 新聞輸入皆為 EIA，補入的 GDELT 統計獨立標示為風險代理。

研究輸入封存為兩個數值快照；排除文章標題、內文與不需要的 checkpoint，保留數值特徵、標籤、價格、來源與可用時間。與原始凍結輸入的特徵、標籤、價格、油價／政策矩陣及時序已逐項驗證完全一致，並保留原始檔案的派生雜湊。

## 驗證與重現

研究測試 31 項通過，包括未來標籤與未來來源不能改變較早預測、缺值遮罩、重疊視窗、柴油獨立拒絕及平行結果一致性。數值快照與原始完整輸入的等值檢查通過。測試通過僅代表程式與時序檢查，精度門檻仍為失敗。

```sh
python3 -m pip install -r research/requirements-mae.txt
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python3 -m unittest discover -s research/mae_tests -q
mkdir -p output/frozen-v6
tar -xJf data/research/stability-inputs-v6-20261103.tar.xz -C output/frozen-v6
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python3 research/weekly_stability.py --inputs output/frozen-v6 --variant v6 --context data/research/stability-context-20261103.json.gz --output output/replayed-v6 --workers 4
```

v7 改用 v7 快照、輸出目錄及 `--variant v7`。GitHub workflow 平常使用版本控制中的固定輸入；可選的來源更新只產生獨立原始統計成品，不自動取代精度測試輸入。完整報告、選擇雜湊及所有逐週預測已保留在 `research/results/`。

尚缺的關鍵證據是完整、可驗證的亞鄰稅前限價與公告前政策資料，以及模型凍結後的新週次表現。本輪新增代理資料並未解決這個問題；這兩個 PR 維持未通過升級的草稿。
